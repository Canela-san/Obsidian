cda estrutura de rede domestica utiliza um HGU (Home Gateway Unit), comumente erroneamente chamada de modem, Ele é um aparelho "faz-tudo", projetado para ser barato e atender ao usuário comum.
- Ele tenta fazer quatro coisas ao mesmo tempo:
	1. Receber o sinal de luz da fibra óptica.
	2. Fazer o roteamento e gerenciamento da rede (atribuir IPs, firewall).
	3. Distribuir a internet via cabo (Switch de 4 portas).
	4. Transmitir o sinal Wi-Fi.
para melhorar a rede doméstica basta separar as etapas em aparelhos especializados:
1. [[ONU (Optical Network Unit)]]
2. [[Roteador (Router)]]
3. [[Switch]]
4. [[AP (Access Point)]]
